*Данные для защиты + способы защиты*

1. Идентификационные данные: шифрование + RBAC

2. Контактные данные: шифрование или обфускация + обезличивание для аналитики

3. Сканы документов: шифрование (EFS)

4. Медицинские данные: шифрование + обезличивание для R&D

5. Платёжные данные: TLS + шифрование в 1С

6. Кадровые данные: шифрование в 1С

7. Аналитические данные: обфусация при отображении \ обезличивание при экспорте

*список инструментов, способов и мер, которые позволят обеспечить конфиденциальность данных в указанных потоках*

1. Пациент → Ресепшен (личные данные)

Меры: использование защищённых веб-форм, минимизация данных, хранение временных анкет в защищённых временных хранилищах, контроль доступа сотрудника
Инструменты: HTTPS, TLS, Локальные клиентские терминалы без возможности копирования

2. Ресепшен → Файловый сервер (скан, Excel)

Меры: шифрование файловой системы, ролевой доступ через AD-группы, аудит доступа к папке, сканирование на вирусы
Инструменты: EFS, BitLocker, Windows File Server, DLP-systems

3. Врач → Excel\скан → Файловый сервер

Меры: централизованная медицинская система, шифрование файлов при сканировании
Инструменты: EMR-systems

4. Кассир → 1С Бухгалтерия

Меры: исключить дублирование в Excel, использовать встроенные права доступа 1С, журналирование операций
Инструменты: 1С с разграничением прав доступа, аудитом входа и журналом изменений

5. ККМ → 1С (OLE)

Меры: мониторинг сетевого трафика
Инструменты: IDS/IPS (Snort, Suricata)

6. Бухгалтерия → 1С

Меры: многоуровневая авторизация, разделение по ролям в 1С, шифрование БД 1С
Инструменты: Active Directory + 1С

7. 1С → Налоговые органы

Меры: использовать сертифицированные крипто-каналы
Инструменты: КриптоПро, СКЗИ, ЭЦП

8. Склад → 1С Торговля и склад → 1С Бухгалтерия

Меры: верификация данных перед синхронизацией, журнал транзакций
Инструменты: 1С Enterprise Bus

9. Файловый сервер → Jupyter→ Аналитик

Меры: автоматическое тегирование выгрузок (ANO), обезличивание при экспорте, jupyter на сервере в изолированной сети, ограничение внешних подключений
Инструменты: Faker, Anonymizer, JupyterHub, VPN
